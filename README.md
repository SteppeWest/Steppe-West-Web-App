# Steppe West Yii2 Web App

This is a web application, in Yii2, for the very specific use case of Steppe West on Hostinger. I have given no consideration to how useful it may be to anyone else. If you do find anything here useful, do what you like with it.

Docs are excluded from the repository until (and if) I make a version without confidential information.

The essential structure is...

```tree
root/
├─ docs/
│  └─ // Whatever docs I publish
├─ p2-yii2/
│  ├─ // Yii2 application
│  ├─ backend/
│  ├─ common/
│  ├─ console/
│  ├─ docs/
│  ├─ environments/
│  ├─ frontend/
│  ├─ static/
│  ├─ vendor/
│  ├─ codeception.yml
│  ├─ composer.json
│  ├─ init
│  ├─ LICENSE.md
│  ├─ README.md
│  ├─ requirements.php
│  ├─ yii
│  └─ yii_test
├─ public_html/
│  ├─ // Relocated frontend/web folder
│  └─ sub_admin/
│     └─ // Relocated backend/web folder
├─ LICENSE
├─ README.md
└─ sw
```
